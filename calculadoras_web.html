Versión Web de las Calculadoras

Estas calculadoras son la adaptación web de los proyectos desarrollados por los alumnos de 6°2° en Powershell y Windows Forms. Durante la cursada, los estudiantes diseñaron e implementaron calculadoras funcionales utilizando:

  • Powershell como lenguaje principal
  • Windows Forms para la interfaz gráfica clásica al estilo Visual Basic
  • Manejo de eventos, validaciones y controles
  • Diseño de interfaz inspirado en calculadoras históricas y modernas

La versión web mantiene el espíritu visual y funcional de los trabajos originales, permitiendo acceder a ellos desde cualquier navegador.
