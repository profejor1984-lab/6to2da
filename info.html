Información del Sitio Web

Cómo los alumnos de 6°2° crearon su propia página web

Inicio La Máquina Máquina Virtual Calculadoras

1. Compra del dominio en NIC.ar

Los alumnos aprendieron que un dominio es el nombre único que identifica un sitio web en Internet. Por ejemplo, 6to2da.com.ar es el dominio elegido para este proyecto.

Se registró mediante NIC.ar, el organismo oficial que administra los dominios .ar en Argentina. Allí se realizó la compra, activación y delegación inicial del dominio.

2. Uso de Cloudflare

Luego se configuró el dominio en Cloudflare, un servicio que permite administrar los DNS, mejorar la seguridad y acelerar la entrega del sitio.

En esta etapa los estudiantes aprendieron a:

  • Cambiar los servidores de nombre (nameservers).
  • Agregar registros DNS tipo A y CNAME.
  • Esperar la propagación del DNS hasta que el dominio quedara activo.

3. Publicación del sitio con GitHub Pages

Finalmente, el sitio fue subido a un repositorio de GitHub y publicado mediante GitHub Pages. Este servicio permite alojar sitios web estáticos gratis y de forma muy simple.

Los alumnos configuraron:

  • El repositorio del curso: 6to2da.
  • La rama main como fuente del sitio.
  • La conexión entre GitHub Pages y el dominio personalizado.

Así, cada archivo HTML del repositorio se transforma automáticamente en una página pública accesible desde Internet.

Resultado final

Gracias a estos pasos, los estudiantes lograron montar un sitio web real, con dominio propio y publicación profesional. Este proyecto integra conocimientos de redes, gestión de DNS, sistemas operativos y aplicaciones web.
